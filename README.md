# One-Click E-Commerce Stroefront 🚀

A modern, responsive, and high-performance e-commerce storefront built with the latest web technologies including Next.js 16, React 19, and Tailwind CSS v4. 

![One-Click Cover](https://res.cloudinary.com/dny7zfbg9/image/upload/v1773738054/m0fumm3fo7jxybtkb8nk.png)

## 🌐 Live Demo
Check out the live beta version of the site on Vercel:
**[https://one-click-beta.vercel.app/](https://one-click-beta.vercel.app/)**

## ✨ Features

- **Modern Architecture**: Built with Next.js App Router leveraging server components for blazingly fast page loads.
- **Dynamic Content**: Integrates completely with the [DummyJSON API](https://dummyjson.com/) to fetch real-time mock data for products like laptops, smartphones, and tablets.
- **Rich UI & Interactions**: 
  - Smooth component animations using **Framer Motion** and **tw-animate-css**.
  - Beautifully crafted, accessible UI components from **Shadcn UI** and **Base UI**.
  - Crisp and scalable icons using **Lucide React** and **HugeIcons**.
- **Responsive Design**: Carefully laid-out UI that looks stunning on mobile, tablet, and desktop devices.
- **Future-Proof Stack**: Harnessing the power of React 19 and the next-generation Tailwind CSS v4 engine.

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

- Node.js (v20 or higher recommended)
- `pnpm` package manager

### Installation

1. **Clone the repository** (if applicable):
   ```bash
   git clone <repository-url>
   cd one-click
   ```

2. **Install dependencies**:
   Using `pnpm` is highly recommended for this project.
   ```bash
   pnpm install
   ```

3. **Start the development server**:
   ```bash
   pnpm dev
   ```

4. **Open the app**:
   Navigate to [http://localhost:3000](http://localhost:3000) in your browser to see the application running.
